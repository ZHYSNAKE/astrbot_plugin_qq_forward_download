# AstrBot 插件：QQ 聊天转发消息下载器（astrbot_plugin_qq_forward_download）

## 插件简介

`astrbot_plugin_qq_forward_download` 是一个专为 AstrBot 框架 和 NapCat 适配器 设计的插件，用于**监听 QQ 会话中的转发消息**（即 `forward` 消息类型），并按照原始转发消息的内容顺序，**递归地将其中的文本、图片、文件以及嵌套的转发消息下载并保存到本地磁盘**。

不支持 动画表情 下载

该插件解决了用户需要手动逐条保存转发消息中内容的痛点。当你在聊天中向机器人发送一条包含多段内容（如文字、图片、文件、其他转发消息）的转发消息时，插件会自动解析并依次保存为编号清晰的文件或文件夹，并可在完成后向你汇报结果。

- **插件名称**：QQ 聊天转发消息下载器（astrbot_plugin_qq_forward_download）
- **作者**: ZHYSNAKE

## 功能说明

该插件提供以下核心功能：

1. **监听会话转发消息**  
   自动捕获 QQ 会话中收到的所有转发消息（`forward` 类型），无需手动指令。

2. **按顺序编号命名**  
   严格依照转发消息中内容出现的先后顺序，用数字（`1`、`2`、`3`...）对每个内容单元进行命名。具体规则：
   - 文本内容 → 保存为 `N.txt`（例如 `1.txt`）
   - 单张图片 → 保存为图片文件 `N`（例如 `2`，扩展名根据实际图片格式而定）
   - 多个图片合并的消息 → 保存为一个文件夹 `N`，内部图片按 `1`、`2`、`3` 顺序排列
   - 嵌套的转发消息 → 保存为文件夹 `N`，并递归执行相同的下载逻辑
   - 其他文件 → 保存为原始文件 `N`（例如 `5.exe`、`5.zip`）

3. **递归处理嵌套转发**  
   当转发消息中再包含其他转发消息时，插件会将嵌套转发保存到子文件夹中，并按照同样的规则逐层下载，不限层级。

4. **自动避让已存在目录**  
   如果默认的 `1` 文件夹已经存在，则自动向后顺延使用 `2`、`3` 等，避免覆盖已有文件。

5. **下载结果通知**  
   全部内容下载完成后，向用户发送一条汇总消息，详细说明下载了哪些内容以及文件保存的具体位置。

### 使用步骤

1. 确保机器人已登录 QQ 并处于聊天可用状态。
2. 在 QQ 聊天窗口中，直接向机器人发送一条转发消息（可以是包含文字、图片、文件、其他转发消息的任意组合）。
3. 插件会自动检测并开始下载，无需输入任何命令。
4. 下载完成后，可以让机器人回复一条汇总消息，告知下载内容与保存位置。


### 示例

假设你向机器人发送了一条转发消息，其内容从上到下依次为：

1. 一段文字“你好”
2. 一张图片
3. 两条合并的图片
4. 另一条转发消息
5. 一个 PDF 文件

插件处理后的目录结构如下：

```
<存放位置>/
└── 1/
    ├── 1.txt          # 文字“你好”
    ├── 2.jpg          # 第一张图片
    ├── 3/             # 两条合并图片的文件夹
    │   ├── 1.jpg
    │   └── 2.jpg
    ├── 4/             # 嵌套转发文件夹
    │   ├── 1.txt      # 嵌套转发内部的文字
    │   ├── 2.png      # 嵌套转发内部的图片
    │   └── ...
    └── 5.pdf          # PDF 文件
```

> 若 `1` 文件夹已存在，则自动改用 `2`、`3` 等文件夹，避免冲突。

## 配置说明

| 配置项 | 说明 | 默认值 |
| --- | --- | --- |
|save_path|保存相对地址|plugin_data/astrbot_plugin_qq_forward_download/downloads|  
|session|监听的聊天(UMO)，不填全部聊天都监听|空|  
|user|只接收谁的消息，填uid，不填全部都接收|空|  
|say_group|在群聊中是否发送下载位置的消息|false|  
|say_private|在私聊中是否发送下载位置的消息|true|
